Privacy policy

Last updated: November 23, 2026

Morning Brief is a personal program that runs only on its owner's own computer. This policy explains what it does with Google account data.

What data it accesses

  • Gmail (read-only): the sender, subject and short preview of recent unread inbox messages.
  • Gmail (send): used only to send the finished brief to the signed-in account's own address. It cannot send to anyone else.
  • Google Calendar (read-only): today's events (time, title, location) from the user's calendars.

How the data is used

The data is used only to build the user's own morning brief page and to email that page to the user. It is not used for advertising, analytics, profiling, or training any AI or machine-learning model.

Where the data is stored

Everything stays on the user's own computer: the brief pages (deleted automatically after 14 days) and the Google sign-in token. Nothing is sent to the developer or to any server other than Google's own APIs. There is no database and no third-party service.

Sharing

Google user data is never sold, shared with, or transferred to anyone.

Google API Services User Data Policy

Morning Brief's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be removed at any time at myaccount.google.com/permissions, or by deleting the token file from the computer.

Contact

Questions can be raised as an issue at github.com/rymez23/morningbrief/issues.
