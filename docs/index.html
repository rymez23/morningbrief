Morning Brief

A personal project by Phillipe Janvier (PJ)

Morning Brief is a small Python program that runs on its owner's own Windows PC each morning. It builds one page showing today's Google Calendar events, unread Gmail, available software updates for the PC, and new tech, politics and science headlines from public news feeds, then emails that page to the owner's own Gmail address.

It is a personal tool, not a public service. It has no servers, no accounts, and no other users.

The full source code is public: github.com/rymez23/morningbrief.
